# Daveram A — Retro Game Portfolio

A responsive, retro arcade-inspired developer portfolio built with **Next.js 15**, **React 19**, **TypeScript**, **Tailwind CSS 4**, and custom CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Features

- Arcade-inspired welcome screen with pixel-style typography, starfield, UFO and layered city skyline
- Interactive Start Game action and responsive section navigation
- Player profile, skills loadout, experience quest log, selected projects and contact sections
- Responsive layouts, reduced-motion support and accessible button labels

## Stack

Next.js App Router · React · TypeScript · Tailwind CSS 4 · Lucide React
